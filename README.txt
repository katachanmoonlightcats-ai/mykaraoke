マイカラオケ GitHub Pages アップロード一式

1. index.html、ONLY_ME.mp4、ONLY_ME.lrc の3ファイルをGitHubリポジトリの同じ階層（ルート）にアップロードします。ZIPそのものはアップロードしないでください。
2. GitHubでCommit changesを押します。
3. GitHub Pagesで公開したURLを再読み込みしてください。
4. ONLY MEを選ぶと、ONLY_ME.mp4とONLY_ME.lrcを読み込みます。
5. LRCは仮の歌詞・仮タイミングです。プレイリストの編集画面で修正できます。編集した歌詞はブラウザ内に保存され、LRCファイルより優先されます。他の端末に編集内容を反映するにはLRCファイルも更新してください。

注意：動画や歌詞を公開する権利がある場合にのみ公開GitHubへアップロードしてください。
